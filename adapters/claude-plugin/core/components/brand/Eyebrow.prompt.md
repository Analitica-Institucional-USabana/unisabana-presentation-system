Uppercase, tracked kicker that introduces a title. Institutional eyebrow.

```jsx
<Eyebrow>Informe de gestión</Eyebrow>
<h2>Los ingresos crecieron 18&nbsp;% en 2024</h2>
```

Props: `rule` (show the 22px accent bar, default true), `color`. Colour follows `--accent-mid` so it adapts inside a `data-faculty` scope.
