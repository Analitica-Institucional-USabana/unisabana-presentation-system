Featured KPI figure — the institutional way to headline a number.

```jsx
<Stat value="18%" label="Crecimiento de ingresos" delta="3.2 pts" deltaDirection="up" caption="Fuente: Dirección Financiera · 2024" />
```

Value is set large in `--accent`. `delta` + `deltaDirection` show a green/red change; `caption` carries the source and period. Always label units and source on data slides.
