Institutional button with calm hover/press and crisp 4px corners.

```jsx
<Button variant="primary" size="md">Continuar</Button>
<Button variant="secondary">Descargar informe</Button>
<Button variant="ghost" size="sm">Ver más</Button>
```

Variants: `primary` (solid `--accent`), `secondary` (outline), `ghost` (text). Sizes `sm|md|lg`. Fill tracks the active accent — set `data-faculty` on an ancestor to recolour.
